# BehaviorGate v3.5.17

**本版重点：修正状态故障披露、完善评估口径、稳定跨平台回归，并提供可直接下载的完整发行包。**

BehaviorGate 是 Claude Code 的开发行为约束插件，提供子代理预算、完成声明检查、危险模式检查及询问与测试约束。v3.5.17 延续既有运行策略；它不是安全边界，也不承诺替代代码与业务验收。

## 下载

- `behavior-gate-V3.5.17.zip`：完整源码发行包，包含安装器、默认策略、hooks、文档、测试与检查工具。
- `SHA256SUMS.txt`：发行资产的 SHA-256 校验和。
- `behavior-gate-V3.5.17.manifest.json`：对应提交、版本、源码快照与文件清单。

附件位于 [v3.5.17 Release](https://github.com/haotianshuo/behavior-gate/releases/tag/v3.5.17) 页面的 Assets 区域。首次使用建议项目级安装；步骤见包内 `README.md` 和 `install.md`。

## 修复

### 状态读取失败的披露

G7 现在区分“尚未建立状态文件”和“已有状态文件无法读取或解析”。正常首次使用保持安静；损坏、空文件等读取异常会生成说明既有约束可能无法继续执行的告警。

这项修复不改变原有放行策略，也不自动重建或恢复丢失的约束。

### 新要求未保存时的表述

`inject_budget` 使用实际保存结果生成文本。保存失败时，不再宣称“已记录本会话要求”，而是说明“未能保存”及后续工具检查可能无法执行该要求。

这修正的是输出内容，不代表约束已经保存成功，也不代表该文本在所有 Claude Code 界面中都会显示。

### 不受支持的回滚参数

`install.py --rollback` 明确返回非零退出码，不再因参数被接受却没有实现而进入普通预演或安装流程。

**本版没有自动回滚能力。** 安装前请保留配置、hooks 和部署清单；人工恢复流程见 `install.md`。

## 改进

### 统计与样本复核

- `gate_stats.py --cohort` 按源码快照、截止时间和外部用途依据限定分析范围。
- 时间过滤解析时间并统一比较；无法解析的时间单独计数。
- 用途映射进行类型、依据与冲突检查；未知用途不自动归为真实业务。
- `guardrail_triage.py` 导出保留完整 session、源码快照和复核依据列。
- 评分按快照与用途分组，显示样本时间范围，并区分有效分组与历史混合汇总。

这些工具提供评估所需的信息，不会自动将拦截数量换算成准确率或业务收益。

### 跨平台回归

- G7 状态故障披露与 cohort 工具回归加入仓库测试。
- 测试输出使用确定的计数与 UTF-8 编码。
- 保存失败夹具使用子进程级受控故障注入，验证实际保存失败链路；不再依赖不同平台上行为不一致的文件只读标记。
- 保留对错误类型、失败披露和“新禁令未落盘”的具体断言。

### 文档与发行体验

- 主页按定位、能力、快速开始、配置、边界与文档入口重新组织。
- 安装示例明确区分发行包目录与目标项目，补齐部署校验的必需参数。
- 发行 ZIP、校验和与提交身份清单一并提供。
- 历史开发过程和问题记录保留在 CHANGELOG，不再作为首页介绍的主线。

## 升级说明

1. 下载并解压本版 ZIP；不要直接覆盖正在使用的源码目录。
2. 备份目标作用域的 settings、hooks、`behavior-policy.json` 和 `DEPLOY_MANIFEST.json`。
3. 在新包目录预演安装，显式指定原目标项目或全局作用域。
4. 无漂移或第三方冲突时，再执行 `--apply`。
5. 校验受管理部署文件与本版源码身份，随后在真实 Claude Code 会话中确认 hooks 被调用。

默认安装不覆盖已有策略文件。已有自定义策略需要对照本版默认策略；不要为了统一版本文字使用 `--force` 覆盖真实配置。

本版仍是 **3.5.17**；历史 CHANGELOG 中同号的“本地开发轮次”与本次软件发行号不是同一条记录。

## 验证与限制

验证对象是 Release 标签对应的确定提交，不是任意“最新一次”绿色 CI。项目测试矩阵为 Windows、macOS、Linux × Python 3.10、3.12；具体结果可从仓库 Actions 核对。

当前功能回归合计 **494 个用例**，文档检查单独计数。在线模型测试默认不启用；本地与 CI 测试不能替代用户界面和真实业务验收。

需要保留的边界：

- G3 检查证据结构，不验证内容真伪。
- G5 是已知误操作模式的补充检查，不是沙箱或安全边界。
- G7 主要处理询问与测试，不保证完整业务需求理解。
- 语义评审或状态故障时，部分保护可能失效；本版没有改为失败全阻断。
- 告警文本生成已覆盖程序级回归，**状态异常告警在宿主界面中的可见性仍未完成单独验收**。
- 拦截准确率、漏拦率与真实项目中的净效率收益不因本次发行而自动成立。

完整历史和未解决项见 [CHANGELOG.md](../../CHANGELOG.md)，安全说明见 [SECURITY.md](../../SECURITY.md)。
